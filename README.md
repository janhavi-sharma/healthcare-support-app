🏥 Healthcare Support App

A full-stack healthcare support platform designed to assist patients and NGOs in managing care requests, volunteer registrations, and general inquiries.

This application demonstrates the integration of frontend, backend, and a basic AI-powered FAQ chatbot for automated user assistance.

---

🚀 Tech Stack

  Frontend
  - React.js
  - CSS
  - Axios
  
  Backend 
  - Node.js
  - Express.js
  
  Database
  - MongoDB

  Deployment
  - Render (Full Stack Deployment)

---

🤖 AI Concept Used

The application includes a rule-based chatbot that:
- Answers frequently asked questions
- Provides guidance on required form details
- Explains service availability and response times
- Assists users in navigating care support and volunteer registration

This demonstrates an AI-driven auto-response system for FAQs, as required in the assignment.

---

🌍 NGO Use-Case

This platform is designed for healthcare NGOs that:
- Provide patient support services
- Coordinate volunteer assistance
- Handle healthcare-related inquiries
- Offer guidance to families in need

The system streamlines communication between patients, volunteers, and support teams.

📌 Core Features
- Request Care Support Form
- Volunteer Registration Form
- Contact Us Form
- FAQ Chatbot for instant guidance
